Base Infinity X

Hereda la estabilidad y el conjunto de personalizaciones de Project Infinity X, ajustado para este hardware.

🛡

KernelSU listo

Soporte para root moderno sin comprometer la integridad del sistema base.

🔋

Ajustado al Snapdragon 662

Sin perfiles genéricos: el manejo de energía y térmico está calibrado para este chipset específico.

🧪

Builds probadas a mano

Cada versión se prueba en el dispositivo real antes de publicarse — no hay builds "a ciegas".

🗂

Sin bloatware

Solo lo esencial. Lo demás queda a tu elección vía GApps o MicroG.

💬

Soporte directo

Reportá bugs y seguí el progreso directamente con el desarrollador, sin intermediarios.

el proyecto

Compilado enteramente desde un teléfono.

VeconOS no nace en un laboratorio con racks de servidores. Nace en Termux, en un solo dispositivo, con paciencia y sesiones largas de terminal.

$ pkg install build-essentials
$ repo sync --force-sync -j4
